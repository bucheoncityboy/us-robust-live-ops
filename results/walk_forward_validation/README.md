# 확장형 Walk-Forward 검증 결과

> 수정 전 `f0bcd3e`의 보관 결과입니다. 후보 선택형 사후 실험으로 고정 운용 전략 및 독립 사후 실적과 구분합니다. 원본 캐시는 저장소에 없으며 현재 소스의 세션 완전성 검사를 통과한 새 실행 기록은 아닙니다. [수정 기록](../../docs/audit_fixes.md)

기존 후보 4개 중 학습 구간의 SPY 대비 정보비율이 가장 높은 전략을 선택한 뒤, 다음 6개월을 평가했습니다. 2019년 8월부터 학습 구간을 확장하며 총 5회 반복했습니다. 동률은 전략명으로 결정합니다.

| 구간 | 학습 종료 | 평가 기간 | 선택 전략 | 전략 수익률 | SPY 수익률 |
|---|---|---|---|---:|---:|
| 1 | 2023-12-29 | 2024-01-02 ~ 2024-06-28 | Robust_L60_M63_LV20 | 37.17% | 15.22% |
| 2 | 2024-06-28 | 2024-07-01 ~ 2024-12-31 | Robust_L50_RM_LV20 | 27.00% | 8.39% |
| 3 | 2024-12-31 | 2025-01-02 ~ 2025-06-30 | Robust_L60_M63_LV20 | 13.11% | 6.05% |
| 4 | 2025-06-30 | 2025-07-01 ~ 2025-12-31 | Robust_L50_RM_LV20 | 27.90% | 11.00% |
| 5 | 2025-12-31 | 2026-01-02 ~ 2026-06-30 | Robust_L50_RM_LV20 | 116.15% | 10.09% |

연결 평가 수익률 기준 연환산 98.08%, 샤프 2.25, 최대 낙폭 -22.02%입니다. 연환산은 252거래일 기준이며 샤프는 무위험수익률 0 기준입니다. 5개 구간 모두 벤치마크 대비 초과수익을 기록했습니다.

## 체결과 재현

월말 신호를 익영업일 시가에 체결합니다. 리밸런싱 당일 보유자산은 시가로 평가하고 실제 매매금액에 편도 5bp, 왕복 10bp를 적용합니다. 각 구간은 현금에서 시작해 마지막 종가에 청산하며 두 거래의 비용을 모두 반영합니다. 구간별 수익률을 연결한 결과이며 고정 60/20/20 전략과 다릅니다.

`python research/walk_forward_validation.py --mode candidate`로 실행합니다. `data/us/`의 `us_prices_panel.parquet`, `us_open_panel.parquet`, `us_volume_panel.parquet`, `spy.parquet`가 필요합니다. 가격 캐시는 저장소에 포함되지 않으므로 새 다운로드는 동일 결과를 보장하지 않습니다. 원본 캐시 SHA256은 [metrics.json](metrics.json)에 기록했습니다. 일별 평가 결과는 [oos_returns.csv](oos_returns.csv)에 있습니다.

## 해석 범위

이번에 추가한 사후 검증입니다. 기존에 연구한 후보 전략 정의를 사용하므로 과거부터 독립적으로 진행한 실시간 검증을 의미하지 않습니다. 유니버스는 현재 구성종목 기준이며, 과거 구성 이력을 복원한 결과는 아닙니다. 기존 보고서의 5구간 성과 집계와 이번 학습 후 평가 절차는 구분합니다. 기존 Bootstrap 및 파라미터 민감도 분석을 이번 선택 절차에 새로 실행한 것은 아닙니다.
